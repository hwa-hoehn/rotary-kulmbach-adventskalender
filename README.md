# Rotary Adventskalender Kulmbach – Gestaltungsvorschlag

Entwurf für eine neue Seite zur Adventskalender-Verlosung des Rotary Club Kulmbach. Keine offizielle Seite des Clubs.
Inhalte stammen von rotaryclub-kulmbach.de und kulmbach.rotary.de.

- `index.html` – Startseite mit Gewinnzahlen, Losnummer-Suche, Verkauf, Hilfsprojekten und Sponsoren
- `verwaltung.html` – Demo zum Eintragen der Gewinnzahlen (speichert nur im eigenen Browser)
- Seiten werden mit `python3 build.py` aus `src/` erzeugt

Umsetzung: HWA – Höhn Web & Automatisierung, hwa-hoehn.de
